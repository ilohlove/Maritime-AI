# Roadmap (not implemented)

- **Task 01:** foundation, ship particulars, local storage, migrations, mock provider, tests and documentation.
- **Next proposed task — harden the vessel record:** user-reviewed field verification with audit events, explicit vessel selection, safe local export/restore and backup acceptance tests. Confirm scope before implementation.
- **Documents:** local ingestion, document references, extraction previews, source evidence and human verification. Never silently overwrite verified values.
- **Certificates and equipment:** expiry tracking, configurable local reminders and inspection preparation.
- **Knowledge and skills:** curated offline maritime knowledge, permissioned typed skills and checklists.
- **Local AI:** evaluate CPU/RAM budgets on 16 GB Windows hardware, choose optional Ollama/llama.cpp adapters and model distribution/licensing; no cloud dependency.
- **Officer workflows:** email translation/drafting, report templates, form filling and controlled export.
- **Commercial packaging:** Windows installer, signed offline updates, data migration/backups, security review, licensing and measured performance targets.

Each milestone needs user approval, explicit acceptance criteria and safety/data-integrity review. No milestone beyond Task 01 is automatically started.
